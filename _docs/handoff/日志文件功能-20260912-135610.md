## 已完成工作
- 生产日志增强：
  - `logback-spring.xml` 配置 JSON 控制台/文件日志、级别、字符集、目录等环境变量。

- 文件列表 UI：
  - `app.js` 增加 `file-table-wrap`、管理员/普通员工表格 class、`expandedFileNameId`、`toggleFileName(file)` 和 `fileNamePreview(name)`。
  - 文件名默认最多显示 18 个字符并追加 `...`；点击展开完整文本，再次点击收起；翻页时清除展开状态。
